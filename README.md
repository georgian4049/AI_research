# Personal AI Research Projects

This repository serves as a collection of personal AI research initiatives focused on advancing the capabilities of modern machine learning models. The primary goals include:

- Improving the performance and generalization of existing models through architectural modifications, prompt learning, or better training strategies.
- Designing and developing novel model architectures from scratch tailored to specific tasks or datasets.
- Exploring cutting-edge topics in multimodal learning, fine-grained recognition, few-shot learning, and large language models (LLMs).

Each project is self-contained within its respective directory and includes its own `README.md` file detailing the problem statement, methodology, experiments, and results. Please refer to those individual files for in-depth explanations.

---

## 📂 Featured Project: `CLIP_improvement`

### 🔬 Leveraging Hierarchies via Multimodal Prompt Learning for Fine-Grained Image Recognition

This project presents a **hierarchical prompt learning framework** for improving **fine-grained image classification** using the **CLIP** (Contrastive Language–Image Pretraining) vision-language model.

**Key highlights:**
- Utilizes **hierarchical label information** (e.g., coarse and fine-grained labels) to enhance classification accuracy.
- Evaluates performance in both using both fine and hierarchical lables:
  - **Few-shot (16-shot)** settings
  - **Fully supervised (all-shot)** setups
- Demonstrates how incorporating semantic structure through prompt design can significantly improve recognition, especially in low-data regimes.

📄 For full details, refer to: [`CLIP_improvement/README.md`](./CLIP_improvement/README.md)
